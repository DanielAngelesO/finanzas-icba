# Instrucciones para agentes

## Carpeta privada de notas

- Trata `workspace/` (relativa a la raíz del repositorio) como una carpeta privada del usuario y mantenla fuera del alcance de todas las tareas.
- No abras, leas, busques, indexes, resumas, cites, modifiques, muevas ni elimines archivos dentro de `workspace/`.
- Excluye `workspace/` de búsquedas recursivas, recopilación de contexto, análisis, pruebas y comandos de mantenimiento.
- Solo accede a un archivo dentro de `workspace/` si el usuario lo solicita explícitamente como parte de la tarea actual.
